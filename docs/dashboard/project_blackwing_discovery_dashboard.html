Competitor Intelligence

The global remote access market is currently defined by architectural transition. Incumbent solutions (TeamViewer, AnyDesk) are facing attrition due to monetization heuristics and security breaches. This landscape analysis evaluates the technical strengths and commercial vulnerabilities of the primary market actors to define Project Blackwing's entry vector.

TeamViewer

Enterprise Standard

Proprietary closed-source protocol. Bills based on named users and concurrent channels.

Primary Vulnerability:

Aggressive "Commercial Use" detection engine resulting in false-positive lockouts.

AnyDesk

Performance Focused

Uses DeskRT codec for high-contrast GUI compression. 60 FPS standard.

Primary Vulnerability:

Major 2024 security breach compromising code-signing keys and source code.

Splashtop

Value Segment

High performance (240 FPS) with competitive tiered pricing. Uses TLS/AES-256.

Primary Vulnerability:

Complex tier-based feature gating (SOS vs Enterprise vs Performance).

RustDesk

OSS / Self-Hosted

Rust backend, Flutter frontend. Native self-hosting using hbbs/hbbr daemons.

Primary Vulnerability:

Lacks native multi-tenancy and granular audit logging; recent cryptographic design flaws.

Chrome RD

Browser Native

Leverages WebRTC for low-latency sandboxed streaming via Google infrastructure.

Primary Vulnerability:

No enterprise orchestration, terminal utilities, or advanced file-system support.

Transport Layer Architecture

Achieving sub-40ms startup and sub-50ms latency requires an evolution beyond legacy TCP-based protocols. We analyzed RDP, WebRTC, and the emerging Media over QUIC (MoQ) standards to define Blackwing's transport stack.

Protocol Performance Metrics

RDP (Legacy TCP) Poor (Head-of-Line Blocking)
WebRTC (RTP/UDP) Good (Complex Signaling)
Blackwing (MoQ/QUIC) Optimal (0-RTT Handshake)

Typical Routing (RustDesk-Style)

Client A
Rendezvous (hbbs)
Client B
P2P Direct Fails? -> Fallback to Relay (hbbr)

Why QUIC (Media over QUIC)?

No HOL Blocking

Unlike TCP, QUIC streams are independent. One lost packet doesn't stall the entire screen update.

0-RTT Resume

Clients resume sessions in under 40ms by bypassing the initial TLS handshake on repeat connections.

Port 443 Multiplexing

Blackwing's Go-based relay inspects the first byte to serve both TCP and TLS on a single port to bypass DPI.

Security & Vulnerability Audit

Project Blackwing's security posture is built on an audit of competitor failures. We examined major CVEs from 2024-2026 to ensure our architecture is resilient against static nonces, predictable keys, and privilege escalation.

CVE-2026-30785 (RustDesk)
Static Nonce Attack

Used twenty-four zero bytes as a nonce with predictable machine UUIDs, allowing local credential decryption.

Blackwing Fix: ChaCha20-Poly1305 with unique 96-bit nonces derived from active system entropy.
CVE-2024-52940 (AnyDesk)
IP Leak via Handshake
IP Leak via Handshake

Direct connection handshake leaked the client's public IP address via AnyDesk ID packets.

Blackwing Fix: Blinded Handshake Negotiation (SRP-6a) ensuring no identifiable IP data is shared without authorization.
